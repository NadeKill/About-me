# Kizuna Sushi House Website Template

Premium static website model for a sushi restaurant, omakase counter, or boutique Japanese dining room.

## Included

- Responsive restaurant homepage
- Premium hero section with local sushi artwork
- Menu section with working category filters
- Omakase and private dining sections
- Reservation form with front-end confirmation state
- Offline-friendly SVG visual assets

## Preview

Open `index.html` in a browser, or run:

```bash
node server.js
```

Then visit `http://127.0.0.1:4173`.

## Customize

Edit `index.html` for restaurant name, menu items, prices, and copy. Edit `styles.css` for colors, spacing, and typography.
